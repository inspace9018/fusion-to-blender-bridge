Fusion 360 to Blender workflow: keep your materials when the CAD changes

Updated September 2026 · for product designers who model in Fusion and render in Blender

The problem: every time you re-export from Fusion and re-import into Blender, the model arrives as new objects. The materials, modifiers, light links and edge marks you set up were on the old objects, so you set them up again.

The fix: replace only the geometry and leave the Blender objects alone. You can do it by hand (two workarounds below) or with a sync add-on that does it on every revision.

Why re-importing loses your setup

An import creates new objects with new mesh data. Blender has no way to know that Body3 in today's FBX is the same part as Body3 from last week. Your shader assignments, a Bevel modifier, a light that only lights the logo, the Sharp edges you marked for clean shading: all of it lives on the old objects.

On a product that goes through ten revisions before launch, that is ten rounds of the same setup.

Workaround 1: link materials across

  1. Import the new version next to the old one.
  2. Select the new part, then Shift-select the old part so it is active.
  3. Press Ctrl L → Link Materials. The material slots copy across.
  4. Repeat per part, then Ctrl L → Copy Modifiers if you use them, and delete the old objects.

Works, but it is per part, and edge marks and light links still need redoing.

Workaround 2: swap the mesh data

  1. On your original objects, set each material slot's link to Object instead of Data (the dropdown next to the material name). The material now belongs to the object, not the mesh.
  2. Import the new version.
  3. Select an original object, open Object Data Properties, and pick the new mesh from the mesh dropdown.
  4. The object keeps its materials and modifiers with the new shape. Delete the imported objects.

Better, but still one part at a time, and hand-marked edges on the old mesh do not carry to the new one.

The sync workflow

  1. Sync once. Fusion Bridge sends the model at real-world size, components as collections.
  2. Build the look in Blender. Materials, modifiers, light links, Sharp and Seam marks, as you normally would.
  3. Revise in Fusion. Move a hole, change a fillet, add a part.
  4. Press Sync again. Each body's geometry is replaced in place. Everything you set up in Blender stays on it, including hand-marked Sharp, Seam, Crease and Bevel Weight. New bodies arrive as new objects; bodies you hid in Fusion can be shown or hidden instantly.

Use Sync Selected when you only changed one part and do not want to wait for the whole assembly.

Tips for a clean revision loop

  • Edit bodies, don't recreate them. The bridge follows each body by Fusion's own identity, so renaming is fine. A body you delete and model again is a new body and arrives as a new object.
  • Build the look in Blender, not Fusion. Fusion appearances are placeholders for a render. (Bridge Pro can bring Fusion colours across as a starting point.)
