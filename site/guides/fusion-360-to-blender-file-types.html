Fusion 360 to Blender file types compared

Updated September 2026 · STL vs OBJ vs FBX vs USDZ vs STEP

Short answer: export FBX for an assembly you render once, STL for one quick part, STEP when you want exact CAD surfaces and have a STEP importer. If you will revise the design and render again, skip files and sync directly.

What each format keeps

Fusion exports solids (STEP, IGES, SAT, SMT) and meshes (FBX, OBJ, STL, 3MF, USDZ) from File → Export. For Blender, these are the ones that matter.

"Keeps your Blender setup" means materials, modifiers, light links and edge marks you added in Blender survive when the Fusion design changes and you bring it in again.

STL

The simplest route. Right-click a body → Save as Mesh, or File → Export. STL has no units: Fusion writes millimetres, Blender reads metres, so the model arrives 1000× too big. Set the import scale to 0.001. Everything arrives as triangles with no colour.

OBJ

Similar to STL for Blender purposes: no units, no hierarchy. Use it when another app in your pipeline prefers OBJ.

FBX

The usual pick for assemblies. Parts come in as separate objects, which makes assigning materials per part practical. Check the scale once on import and keep the same settings afterwards.

USDZ

Recent Fusion versions export USDZ, which Blender imports through its built-in USD importer. It is designed for AR viewing, so results vary; worth a try if you need a quick look with materials.

STEP

STEP carries the exact CAD surfaces instead of a mesh, so you choose the mesh density when importing. Blender needs an add-on for it. STEP is the best route when files also come from SolidWorks, Onshape or other CAD tools.

No file: live sync

Fusion Bridge sends the model from Fusion to Blender directly: real-world size, components as collections, mesh quality presets. When the design changes, it replaces only the geometry, so the setup you built in Blender stays. The free full installer also includes a STEP reader for files from other CAD tools.
