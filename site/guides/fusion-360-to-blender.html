Fusion 360 to Blender: every way to move a model

Updated September 2026 · for Fusion (formerly Fusion 360) and Blender 4.2 or newer

Short answer: Blender cannot open .f3d files. You either export a file from Fusion and import it in Blender, or you use a bridge add-on that sends the model directly.

For a one-off render, export FBX (keeps separate parts) or STL (simplest) and fix the scale. If you will change the design and render it again, a direct sync saves the most time, because a re-imported file wipes the materials you set up in Blender.

Route 1: export a file (STL, OBJ or FBX)

  1. In Fusion: File → Export, choose the format and save. For STL you can also right-click a body and choose Save as Mesh to set the refinement.
  2. In Blender: File → Import and pick the same format. STL, OBJ, FBX and USD importers are built in.
  3. Fix the scale. Fusion works in millimetres; STL and OBJ carry no units, so Blender reads 50 mm as 50 m. In the import dialog set Scale to 0.001, or select everything and press S 0.001 Enter.
  4. Smooth the shading. CAD meshes are triangulated; use Shade Auto Smooth so flat faces stay flat and curved faces look curved.

Route 2: STEP with an importer add-on

STEP keeps the exact CAD surfaces, so the importer can mesh them at the density you choose. Blender has no built-in STEP reader; several add-ons exist, free and paid. Use this route when you receive STEP files from other CAD tools too. Fusion Bridge's free full installer also includes a STEP reader.

Route 3: sync directly from Fusion

A bridge add-on skips the file. Fusion Bridge runs a small add-in inside Fusion and a panel inside Blender. Press Sync and the model arrives at real-world size, with Fusion components as Blender collections.

The part that matters most shows up on the second sync. When you change the design in Fusion and sync again, only the geometry is replaced. The materials, modifiers, light links and the Sharp, Seam, Crease and Bevel Weight marks you set in Blender stay where they were. With exported files, every revision arrives as new objects and you set all of that up again.

Which one should you use?

  • One render, never changing: FBX, scale checked. Done in five minutes.
  • Files from other CAD tools as well: STEP with an importer.
  • A product you will revise and re-render: a live sync. The time saved grows with every revision.

Common questions

Can Blender open Fusion 360 files directly?

No. Blender cannot read .f3d. Export to a mesh format or STEP, or use a sync add-on.

Why is my model 1000 times too big?

STL and OBJ carry no units. Fusion writes millimetres and Blender reads metres. Scale by 0.001, or use a route that carries units.

Do Fusion appearances come across?

Not usefully through STL or OBJ; plan to build the look in Blender. Bridge Pro imports Fusion appearance colours as Blender materials.
