Set up in three steps

The bridge has two halves. The Blender half comes from Blender's extensions platform. The Fusion half comes from here.

  1. 1

    Install the Fusion add-in

    Download the Fusion add-in and extract the zip. Close Fusion, then double-click the installer inside: install.bat on Windows, install.command on macOS.

    macOS blocked it? Right-click the file and choose Open.

  2. 2

    Run it in Fusion

    In Fusion 360: Utilities → Add-Ins → Scripts and Add-Ins, open the Add-Ins tab, select fusion_to_blender_addon_fusion and press Run. Tick Run on Startup so you only do this once.

  3. 3

    Sync from Blender

    In Blender: Edit → Preferences → Get Extensions, search Fusion Bridge and install Fusion Bridge Lite. Then press N in the 3D Viewport, open the Fusion 360 tab and press Sync.

If something does not connect

Blender says "Not Connected"

The Fusion add-in is not running. Open Scripts and Add-Ins in Fusion and press Run on fusion_to_blender_addon_fusion. Blender connects by itself within a few seconds.

I want to open .step files without Fusion

The extensions-platform build leaves out the STEP reader because its CAD engine is larger than the platform allows. The free full build includes it: download the unified installer, which installs both halves at once.
